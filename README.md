# TaskApp Releases

Repositorio público oficial de actualizaciones de **TaskApp**.

Los APK firmados se generan automáticamente mediante GitHub Actions desde el
repositorio privado del proyecto y se adjuntan a la sección **Releases**.

> Este repositorio no contiene el código fuente ni credenciales.

La aplicación consulta la última Release publicada para mostrar las notas,
descargar el APK y abrir el instalador de Android.
